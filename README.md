# 🐍 Python Fundamentals Project | Data Technician Bootcamp

## 🚀 Overview

This project was completed during a Data Technician Bootcamp and demonstrates the use of Python to build logical solutions, perform calculations, and create interactive programs.

Through a series of practical exercises and challenges, I developed programs that utilised variables, user input, type casting, conditional statements, loops, and arithmetic operations. These exercises strengthened my problem-solving abilities and provided a solid foundation in programming concepts that can be applied to data analysis, automation, and software development.

## 🎯 Project Highlights

### 🔢 User Input & Number Manipulation

Created programs that accepted user input, converted values into appropriate data types, and used mathematical operations to manipulate and process data. These exercises demonstrated how Python can handle calculations and solve logical problems.

### 🧮 Interactive Calculator Development

Developed a menu-driven calculator that allows users to perform addition, subtraction, multiplication, and division operations. The program used loops and conditional statements to manage user choices and provide continuous interaction until exit.

### ⚖️ Decision-Making with Conditional Statements

Implemented `if`, `elif`, and `else` statements to control program behaviour and ensure different actions were performed based on user selections and conditions.

### 🔁 Program Flow with Loops

Used `while` loops to create interactive programs that could repeat actions, validate user input, and maintain continuous execution until a specific condition was met.
